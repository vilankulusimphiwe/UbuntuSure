# UbuntuSure

UbuntuSure is a portfolio application for insurance administration. It is not a real insurer.

Staff sign in, then work through customers, quotes, policies, claims, payments, documents, reports, and administration. The dashboard shows a sample book of business.

Built with Angular 21, TypeScript 5.9, and ASP.NET Core 8, with SQL Server.

## Run it locally

1. Create the database with the scripts in `backend/database`.
2. Start the API from `backend/UbuntuSure.Api`:

```bash
dotnet run
```

3. Start the screens from the project folder:

```bash
npm start
```

4. Open http://localhost:4200

Sample sign-in: `snkosi` / `Password1`

GitHub stores this code. It does not run the screens or the database.
